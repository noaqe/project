# Сдача проекта

Преподавателю передаётся ссылка на репозиторий GitHub. В репозитории должны быть исходный код, `pom.xml`, Maven Wrapper, SQL-скрипты, README и диаграммы. Локальные пароли, дампы чужой БД и содержимое сторонних серверов не включаются.

Текст для формы сдачи после публикации:

```text
Курсовой проект: Library Management (Библиотека)
Стек: Java 17, Maven, PostgreSQL, JDBC, JUnit 5.
Репозиторий: https://github.com/noaqe/project
Запуск и настройка БД: README.md.
ER/UML, нормализация и сценарий демонстрации: папка docs.
```

Если преподаватель просит разместить приложение на сервере, нужно отдельно согласовать выделенные каталог, БД/пользователя и способ запуска консольной программы. HTTP endpoint из примера не является адресом PostgreSQL и не указывает способ сдачи ссылки. Не требуется менять существующий пример преподавателя для проверки этого проекта.
