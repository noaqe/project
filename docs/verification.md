# Результаты проверки

Проверено 9 ноября 2026 года на Windows, OpenJDK 24.0.2 и отдельной локальной PostgreSQL 18. Сборка настроена на `--release 17`; исходники используют возможности Java 17. Проверка именно на Java 17 / PostgreSQL 17 предусмотрена отдельным GitHub Actions workflow; локальные результаты ниже не заменяют статус CI.

| Проверка | Результат |
|---|---|
| Maven `package` | Успешно, исполняемый JAR с JDBC-драйвером |
| JUnit: модели и консольный ввод | 26 тестов, 0 ошибок, 0 пропусков |
| PostgreSQL integration | 16 тестов, 0 ошибок, 0 пропусков |
| Общий итог | 42 теста прошли |
| Maven Wrapper | Запуск `mvnw.cmd -v` загружает и запускает Maven 3.9.9 |
| Исполняемый JAR | Успешный проход меню: CRUD книг/читателей, поиск, выдача/возврат, отчёты, некорректный пункт меню, выход |
| CLI | `--init --seed`, `--help`, ненулевой код выхода для неизвестного аргумента |
| ER/UML | Оба PNG отрисованы из PlantUML и просмотрены |

Интеграционные проверки включают M:N с несколькими авторами, поиск без потери соавторов, буквальные `%`/`_` и строку, похожую на SQL-инъекцию, уникальность ISBN/email, rollback создания/изменения книги, выдачу/возврат, лимит и срок GUEST, просрочку, сохранность истории, агрегаты без удвоения фонда, повторную инициализацию и отсутствующие ID.

Два отдельных конкурентных сценария запускают операции через разные JDBC-соединения: два читателя запрашивают последний экземпляр; один читатель одновременно запрашивает две книги при одном оставшемся месте в лимите. В каждом случае успешно завершается только одна операция.

Текст успешного прохода готового JAR: [demo-session.txt](demo-session.txt). В нём только искусственные локальные данные, без настоящих доступов к серверам.

Docker Compose в этой среде не запускался (Docker CLI отсутствует). Приложение и интеграционные тесты проверены с установленной PostgreSQL; конфигурация Compose использует ту же схему и JDBC-подключение. Существующий PostgreSQL пользователя и сервер преподавателя для тестов не изменялись.
